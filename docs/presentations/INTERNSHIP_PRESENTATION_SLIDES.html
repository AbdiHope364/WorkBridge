PROBLEM ANALYSIS

Problem Statement & Motivation

Informal & Fragmented Market

Skilled tradesmen (electricians, plumbers, masons, carpenters) rely on roadside gatherings or unverified word-of-mouth with zero digital visibility.

Trust & Verification Deficit

Employers and homeowners face substantial risk with unverified skills, lack of identity verification, and absence of customer ratings.

Income Instability & Wage Disparity

Workers suffer from erratic employment cycles, untracked bookings, non-standardized pricing, and insecure cash-based transactions.

BUSINESS MODEL

Two-Sided Freemium Marketplace Model

Worker Freemium Tiers

Free: 5 job applications/month. Pro Monthly (299 ETB): Unlimited applications, verified Pro badge, priority search ranking. Pro Annual (2,499 ETB): 1 year unlimited.

Employer Freemium Tiers

Free: 3 job postings, search verified workers. Pro Monthly (599 ETB): Unlimited job postings, applicant tracking pipeline. Pro Annual (4,999 ETB): 1 year unlimited.

Two Distinct Workflows

Supports both Direct Booking (Find -> Book -> Complete -> Review) and Job Application (Post -> Apply -> Shortlist -> Book).

ARCHITECTURE

System Architecture & Monorepo Design

Turborepo & pnpm Monorepo

Single unified repository orchestrating apps/client (Next.js 16), apps/admin (Next.js 16), apps/api (Express.js), and shared packages.

Frontend Layer (Port 3000 & 3001)

Next.js 16 App Router, React 19, TypeScript, Tailwind CSS, Lucide Icons, and shared @repo/ui component system.

Backend REST API (Port 4000)

Node.js and Express.js REST API with JWT authentication, quota enforcement middleware, and cloud persistence in MongoDB Atlas.

PROBLEM SOLVING

Technical Challenges & Solutions

Cross-Origin OAuth 2.0 Integration

Challenge: Cookie isolation between Next.js (3000) and Express (4000). Solution: Configured Next.js App Router reverse-proxy rewrites (/api/:path*).

Strict TypeScript Type Safety

Challenge: Dynamic database payloads causing any lint warnings. Solution: Created comprehensive DTO interfaces in @repo/types with 100% type coverage.

Quota Enforcement Integrity

Challenge: Preventing free users from bypassing limits. Solution: Built backend middleware in jobController returning structured 403 QUOTA_EXCEEDED.
